# СИГНАЛ 404

Интерактивный браузерный хоррор-пранк для отправки друзьям в VK и другие чаты.

## Что умеет
- Адаптивная страница для телефона и компьютера.
- Атмосферная псевдодиагностика с прогрессом и glitch-эффектом.
- Пользователь сам вводит ник; результат выбирается локально.
- Кнопка поделиться результатом через VK.
- Без регистрации, аналитики, камеры, микрофона, геолокации и доступа к перепискам.
- В финале честно раскрывается, что проверка была постановкой.

## Запуск
Откройте `index.html` в браузере или разместите содержимое ветки на статическом хостинге.

## Публикация
Для GitHub Pages репозиторий должен поддерживать Pages и Pages нужно включить в настройках репозитория (Settings → Pages → Build and deployment → GitHub Actions). Для бесплатного публичного сайта репозиторий должен быть публичным. Не меняйте видимость существующего репозитория без отдельного решения владельца.

## Безопасность
Сайт не выполняет реального сканирования устройства и не собирает данные. Все эффекты — вымышленные.
