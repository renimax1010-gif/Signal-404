# ХАОС — Cloudflare Worker для VK Callback API

Это облачный вариант бота. Он не использует платные AI API: ответы формируются локальными правилами и заготовками. Это развлекательный алгоритмический бот, а не полноценная языковая модель.

## Настройка Cloudflare

1. Создать Worker и вставить код из файла cloudflare-worker.js.
2. Создать KV namespace в разделе Workers & Pages → KV. Привязать его к Worker с именем CHAOS_KV.
3. В Worker → Settings → Variables and Secrets добавить:
   - Secret VK_GROUP_TOKEN — ключ сообщества VK с правом сообщений.
   - Secret VK_CALLBACK_SECRET — секретный ключ Callback API.
   - Secret VK_CONFIRMATION_CODE — строка подтверждения Callback API из настроек VK.
   - Text variable VK_GROUP_ID со значением 242755115.
4. Сохранить и развернуть Worker. Скопировать HTTPS URL вида https://имя.workers.dev.

## Настройка VK

1. Сообщество → Управление → Работа с API → Callback API.
2. Добавить сервер и вставить HTTPS URL Worker.
3. Задать секретный ключ (тот же, что сохранён в VK_CALLBACK_SECRET).
4. Выбрать API version 5.199 и включить событие «Входящее сообщение».
5. Взять строку подтверждения из VK, сохранить в Cloudflare как VK_CONFIRMATION_CODE и проверить сервер в VK.

Не отправляйте токен, секрет или код подтверждения в чат либо GitHub.

## Самостоятельные сообщения

В Worker → Triggers → Cron Triggers добавить расписание, например 0 */2 * * * (раз в два часа). Worker отправит одну реплику в последний чат, где увидел входящее сообщение. До первого сообщения в беседе бот не знает её peer_id и не пишет туда.

## Ограничения и безопасность

- Для работы необходим KV binding CHAOS_KV.
- Бесплатные квоты Cloudflare и VK API могут меняться. Не подключайте платный тариф и не включайте платные дополнительные сервисы.
- Автоматические сообщения должны быть умеренными и согласованными с участниками/администраторами беседы.
- Реальный обмен с VK ещё не проверен: его можно проверить только после настройки Worker, секретов и Callback API.
