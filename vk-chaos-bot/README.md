# ХАОС — бесплатный VK chat bot

Лёгкий развлекательный бот сообщества для запуска по требованию. Не использует OpenAI, Groq, Gemini или другие платные AI API.

## Как он «думает»
- Локальные правила и тематические словари: еда, деньги, работа, сон, отношения, игры, погода.
- Определение приветствий, вопросов, просьб пошутить, благодарностей и прощаний.
- Короткая память последних сообщений в рамках текущего запуска.
- Контекстные заготовки, случайный выбор реплик и ограничение повторных вмешательств.
- Это не настоящая языковая модель: бот не понимает произвольные сложные вопросы и не обучается. Его задача — лёгкое развлечение.

## Запуск только когда нужно
Требуется Node.js 20+ и компьютер, на котором бот будет работать во время развлечения.

```bash
cd vk-chaos-bot
npm install
cp .env.example .env
```

В .env укажите свой ключ сообщества в VK и ID сообщества. Затем:

```bash
npm test
npm run check
npm start
```

Остановить бота: Ctrl+C. Когда программа остановлена, бот не читает сообщения и не отвечает. GitHub сам по себе не запускает этот процесс.

## VK
Сообщество должно иметь включённые сообщения, возможности ботов, разрешение добавлять сообщество в чаты, ключ с правом «сообщения сообщества», Long Poll и событие «Входящее сообщение». Возможность получать сообщения из конкретной беседы зависит от прав и настроек VK. Начните с тестовой беседы.

## Настройки
- RANDOM_REPLY_CHANCE — шанс редкой случайной реплики на сообщение (по умолчанию 3.5%).
- RANDOM_REPLY_COOLDOWN_SECONDS — общая пауза между случайными репликами (120 секунд).
- USER_COOLDOWN_SECONDS — пауза для одного участника (300 секунд).
- LOG_MESSAGE_TEXT — не включайте без необходимости.

## Безопасность
Не отправляйте ключ сообщества в чат и не публикуйте его в GitHub. Храните его только в локальном .env, который исключён через .gitignore.
